# 系统流程图 & 功能模块图绘制工具

一个零依赖的单文件（`diagram-tool.html`）可视化绘图工具，用于快速绘制系统流程图与功能模块图，双击即可在浏览器中打开使用。

## 功能特性

- 🖱️ 拖拽式节点/连线绘制，操作直观
- 🔲 内置常用图形（开始/结束、处理、判断、模块等）
- 📐 支持节点对齐、连线与分组
- 💾 本地保存 / 导出，无需联网、无需安装

## 使用方式

直接双击 `diagram-tool.html`，或：

```bash
start diagram-tool.html
```

## 技术栈

- HTML + CSS + 原生 JavaScript（无任何外部依赖）
